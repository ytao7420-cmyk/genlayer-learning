# GenLayer Learning

Personal GenLayer learning notes and original Intelligent Contract experiments.

## SpecCheck

[SpecCheck](speccheck/) is a working procurement review application deployed on GenLayer Studionet. It compares synthetic supplier quotations against immutable RFQ requirements using validator consensus. Source, tests, architecture and actual chain evidence are included.

- [Project source and setup](speccheck/README.md)
- [Deployment record](speccheck/public/deployment.json)
- [Recorded test evidence](speccheck/public/evidence/demo.json)

All demonstration data is synthetic and the test wallets are self-controlled. This repository does not claim rewards, external customers or commercial usage.
